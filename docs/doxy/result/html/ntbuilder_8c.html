Detailed Description

Implementation of network construction functions.

Provides memory allocation and pointer setup for neurons, input/output references, and inter-layer buffers.
Uses memtrack() to manage memory safely.

struct net_s * buildnet ( net_s *  net)

Resolves wiring descriptors and builds the network's internal references.

Return values
NULL
  • net is NULL.
  • net->neurons has not been allocated yet.

If net_s::layers > 1, resolves each net_s::wiring descriptor into a net_s::bff array for its corresponding layer transition (net->bff[0..layers-2]), in two passes:

  • First pass: for arrays with wiring_s::array_type ‘'M’`, each element is resolved individually according to its own wiring_s::src_type.
  • Second pass: for all other arrays, the whole array is resolved at once according to its wiring_s::array_type, and wiring_s::size is updated to match the resolved size. Layer 0 is not processed by either pass.

Then, calls defineneurons() to define neuron_s::inputs for every neuron according to its layer and selected wiring_s::size entry.

Calls buildneurons() to allocate neuron_s::w according to the resolved neuron_s::inputs values.

Finally, sets neuron_s::in for every neuron from layer 1 onward using the net_s::bff entry selected by neuron_s::bff_idx, while neurons on layer 0 receive net_s::in.

Note
wiring_s::array_type (second pass):
  • 'I': Alias to net_s::in.
  • 'O': Alias to net_s::out.
  • 'N': Alias to another already-resolved net_s::bff array, referenced by this array's own wiring_s::src_layer[0] and wiring_s::src_index[0].
  • any other value: left as NULL, with a placeholder size of 1.
wiring_s::src_type, for elements inside a ‘'M’‘ array (first pass):
  • 'N’: net->nn[src_layer][src_index].out.
  • 'O': A single element of net_s::out.
  • any other value: left as NULL.

uint8_t defineneurons ( net_s *  net)

Defines the input count for every neuron.

Return values
1Argument is NULL.
0SUCESS

Defines neuron_s::inputs for every neuron according to its position in the network.

Neurons on the first layer use net_s::inputs as their input count.

Neurons from the second layer onward use the resolved net_s::wiring descriptor selected by neuron_s::bff_idx. The corresponding wiring_s::size value defines the number of inputs for each neuron.

struct net_s * newnet ( net_s *  net,
uint16_t *  neurons_per_layer,
layer_t  layers_size 
)

Allocates the network's neuron and wiring structures.

Return values
NULL
  • net or neurons_per_layer is NULL.
  • net_s::layers is less than 1.
  • layers_size does not match net_s::layers.
  • any per-layer neuron count is less than 1.

Copies neurons_per_layer into net_s::neurons and allocates net_s::nn with one neuron_s array per layer.

When net_s::layers is greater than 1, allocates one net_s::wiring descriptor per layer transition.

Initializes net_s::in, net_s::bff and net_s::out to NULL. These structures are allocated and resolved later by buildnet().

References net_s::bff, createregister(), net_s::in, net_s::layers, net_s::neurons, net_s::nn, net_s::out, and net_s::wiring.
